# Nitter-android
Render a nitter instance in an app: browse X/Twitter without an app.

In addition you can:

- Change the rendered nitter instance
- Have user bookmarks

`install.sh` is a guide on how to install dependencies and build the apk for those who use Arch Linux.

> This is my first time developing an app for Android, and heavily used generative AI for the process. All code has been review, but lack specific Android developing concepts.
